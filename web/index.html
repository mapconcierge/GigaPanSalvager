HOW IT WORKS

入力から、保存まで。

  1. 01

    ID を指定

    パノラマの ID または URL を入力し、GitHub で依頼を確定します。

  2. 02

    自動で取得・検証

    GitHub Actions が全階層を取得。再試行し、画像の破損と欠損を記録します。

  3. 03

    手元に保存

    アーカイブを展開すると GitHub Pages 用のリポジトリ構成。docs/ を公開すればビューアと KML がそのまま使えます。

配信元が停止している場合
未完了として保存されます。復旧後にジョブを再実行すると、キャッシュが残っている検証済みタイルを再利用します。

公開資料を、出典とともに
元資料の著作者・ライセンス表記を保存します。KML は位置・画角情報が取得できた場合に生成されます。
